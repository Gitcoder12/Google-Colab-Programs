# Agent Instructions — Google-Colab-Programs

Read README.md, CONTRIBUTING.md and FEATURE_UPGRADE_PLAN.md first.

- Do not claim notebooks exist unless .ipynb files are committed.
- Build complete notebooks with prerequisites, objective and expected outputs.
- Use lawful public datasets or clearly labelled synthetic data.
- Never put API keys, private files or credentials in notebooks or outputs.
- Pin dependencies where practical; note runtime and compute requirements.
- Validate notebook JSON and execute top-to-bottom in a clean runtime before claiming pass.
- Do not fabricate execution results; work on a branch and open a PR.
