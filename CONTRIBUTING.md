# Contributing to Google-Colab-Programs

This repository currently has no notebooks. Add complete, small, reproducible learning modules.

1. Read README.md and FEATURE_UPGRADE_PLAN.md.
2. Propose one topic with a target learner and learning outcome.
3. Create a notebook that runs from a fresh Colab runtime.
4. Pin dependencies and document dataset/model source and licence.
5. Remove API keys, tokens, local paths and private data from cells/output.
6. Include expected output and common failure notes.
7. Open a PR with a notebook execution result or clearly mark execution as not run.
